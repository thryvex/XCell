# XCell

XCell เป็นโปรแกรมตารางคำนวณ (สเปรดชีต) สำหรับ Windows ใช้งานแบบออฟไลน์ วิธีใช้คล้าย Google Sheets เปิดและบันทึกไฟล์ `.xlsx` ได้ เหมาะกับงานบันทึกรายรับรายจ่าย รายการสินค้า และการคำนวณทั่วไป ข้อความในโปรแกรมเป็นภาษาไทยทั้งหมด

## ทำอะไรได้บ้าง
- สูตรคำนวณพื้นฐาน เช่น `SUM`, `AVERAGE`, `IF`, `SUMIF`, `COUNTIFS`, ฟังก์ชันวันที่และข้อความ รวมถึงอ้างทั้งคอลัมน์ เช่น `=SUM(G:G)`
- คลิกเซลขณะพิมพ์สูตรเพื่อใส่ตำแหน่งเซล, ลากจุดมุมเซลเพื่อคัดลอกสูตร, คัดลอก/ตัด/วางแล้วสูตรปรับตาม
- หลายชีตและอ้างข้ามชีต, ค้นหา, เรียงลำดับ, ตัวกรอง, ซูม, ปุ่มลัดเลื่อนในตาราง
- รูปแบบตัวเลข ฿ บาท / เปอร์เซ็นต์ / วันที่ (แสดงปี พ.ศ. ได้), สีและเส้นขอบ, ผสานเซล, ตรึงแถว/คอลัมน์
- เทมเพลตรายรับรายจ่าย และรายการสินค้า
- นำเข้า/ส่งออก CSV, พิมพ์และบันทึกเป็น PDF, ธีมสว่าง/มืด
- บันทึกไฟล์กู้คืนระหว่างทำงาน เผื่อโปรแกรมปิดผิดปกติ

## ติดตั้งบน Windows
1. ดาวน์โหลดตัวติดตั้ง `XCell.Setup.0.1.0.exe` จากหน้า [Releases](https://github.com/bosschaisit/XCell/releases)
2. เปิดไฟล์ที่ดาวน์โหลด
3. ตัวติดตั้งยังไม่ได้เซ็นชื่อดิจิทัล Windows จึงอาจขึ้นหน้าต่างสีน้ำเงิน "Windows protected your PC" (SmartScreen)
   - คลิก **More info** (ข้อมูลเพิ่มเติม)
   - คลิกปุ่ม **Run anyway** (เรียกใช้ต่อไป) ที่ปรากฏขึ้น
4. ทำตามขั้นตอนของตัวติดตั้ง (เลือกโฟลเดอร์ติดตั้งได้) ตัวติดตั้งจะสร้างทางลัด XCell ในเมนู Start และบนเดสก์ท็อป

เปิดไฟล์ด้วย XCell: คลิกขวาที่ไฟล์ `.xlsx` หรือ `.csv` > **Open with** (เปิดด้วย) > XCell ตัวติดตั้งไม่ตั้ง XCell เป็นโปรแกรมเริ่มต้นของไฟล์เหล่านี้ หรือเปิดจากในโปรแกรมด้วยปุ่ม "เปิด" / ลากไฟล์มาวางบนหน้าต่าง

## เปิดไฟล์ใน Google Sheets
1. อัปโหลดไฟล์ `.xlsx` ที่บันทึกจาก XCell ขึ้น Google Drive
2. ดับเบิลคลิกไฟล์ใน Google Drive แล้วเลือกเปิดด้วย Google Sheets (หรือใน Google Sheets ไปที่เมนู ไฟล์ > นำเข้า > อัปโหลด)
3. ถ้าจะนำไฟล์กลับมาแก้ใน XCell ใน Google Sheets ไปที่ ไฟล์ > ดาวน์โหลด > Microsoft Excel (.xlsx)

## ข้อจำกัดของเวอร์ชัน 0.1.0
- **กราฟ:** สร้างหรือแสดงกราฟในโปรแกรมไม่ได้ ถ้าเปิดไฟล์ที่มีกราฟแล้วบันทึกทับ กราฟในไฟล์จะหายไป (โปรแกรมขึ้นแถบเตือนตอนเปิดไฟล์ และถามก่อนบันทึกทับ พร้อมตัวเลือก "บันทึกเป็นไฟล์ใหม่")
- **ความกว้างคอลัมน์ใน Google Sheets:** คอลัมน์ที่ตั้งความกว้างเองแต่ไม่มีข้อมูลเลย Google Sheets จะไม่ใช้ความกว้างนั้น (แสดงเป็นความกว้างเริ่มต้น)
- **รองรับเฉพาะ Windows** ยังไม่มีเวอร์ชัน macOS
- **ยังไม่มี virtual scrolling:** ตารางวาดทุกแถวที่มี เมื่อข้อมูลหลายพันแถวการเลื่อนอาจช้าลง (รองรับสูงสุด 10,000 แถว × 702 คอลัมน์)
- ส่วนอื่นในไฟล์ที่โปรแกรมไม่รองรับ เช่น Pivot, การจัดรูปแบบตามเงื่อนไข, การตรวจสอบข้อมูล, รูปภาพ จะหายเมื่อบันทึกทับ (โปรแกรมแจ้งเตือนตอนเปิดไฟล์)
- ยังไม่ได้ทดสอบการเปิดไฟล์กับ Microsoft Excel

## สำหรับนักพัฒนา
ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install                                  # ติดตั้ง dependency
npm run dev                                  # รันโหมดพัฒนา
npm test                                     # เทสต์ (Vitest)
npm run build                                # build โค้ด
npx electron-builder --win --publish never   # สร้างตัวติดตั้ง Windows ในโฟลเดอร์ release/ (ไม่อัปโหลด ไม่ต้องใช้ GH_TOKEN)
```
