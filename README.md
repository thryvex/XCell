# XCell (โปรแกรมตารางคำนวณสำหรับบันทึกรายรับรายจ่าย)

XCell คือโปรแกรมตารางคำนวณฉบับง่ายที่ออกแบบมาสำหรับการบันทึกรายรับรายจ่าย รายการสินค้า และการคำนวณพื้นฐาน ติดตั้งลงเครื่องคอมพิวเตอร์ ทำงานแบบออฟไลน์ 100% ไม่ต้องเชื่อมต่ออินเทอร์เน็ต และส่งออกเป็นไฟล์ `.xlsx` ที่นำไปเปิดและใช้งานต่อใน **Google Sheets** หรือ **Microsoft Excel** ได้อย่างสมบูรณ์แบบ

---

## จุดเด่น
- **ใช้งานง่าย ไม่ต้องจำสูตร:** มีปุ่มคำนวณอัตโนมัติ (Σ รวม, เฉลี่ย, นับ, ต่ำสุด, สูงสุด) และคลิกเซลล์สร้างสูตรได้
- **เข้ากันได้กับ Google Sheets:** รองรับไฟล์ `.xlsx` ครบถ้วน ทั้งสูตร, การผสานเซลล์, รูปแบบตัวเลข (฿ บาท, วันที่, เปอร์เซ็นต์)
- **ภาษาไทยทั้งระบบ:** เมนู ข้อความช่วยเหลือ และข้อความแจ้งเตือนข้อผิดพลาดเป็นภาษาไทยที่บอกวิธีแก้ไขชัดเจน
- **ปลอดภัย ข้อมูลไม่สูญหาย:** มีระบบ Undo/Redo ย้อนกลับได้ บันทึกไฟล์แบบปลอดภัย และกู้คืนข้อมูล

---

## วิธีเปิดไฟล์ใน Google Sheets
1. อัปโหลดไฟล์ `.xlsx` ที่บันทึกจาก XCell ขึ้นบน **Google Drive** ของคุณ
2. ดับเบิลคลิกที่ไฟล์ใน Google Drive เพื่อเปิดด้วย **Google Sheets** (หรือเปิด Google Sheets แล้วเลือก เมนู *ไฟล์ > นำเข้า > อัปโหลด*)
3. สูตร การคำนวณ และการจัดรูปแบบทั้งหมดจะทำงานต่อใน Google Sheets ได้ทันที

### ข้อจำกัดที่ควรรู้
- **ความกว้างคอลัมน์ที่ไม่มีข้อมูล:** Google Sheets ใช้ความกว้างที่ตั้งไว้เฉพาะคอลัมน์ที่มีเซลอย่างน้อยหนึ่งเซล คอลัมน์ที่ปรับความกว้างไว้แต่ไม่มีข้อมูลเลยจะกลับเป็นความกว้างเริ่มต้นเมื่อเปิดใน Google Sheets

## สำหรับนักพัฒนา (Development)

### ความต้องการของระบบ
- Node.js version 20 LTS ขึ้นไป
- npm (มาพร้อมกับ Node.js)

### การติดตั้ง Dependencies
```bash
npm install
```

### การรันในโหมดพัฒนา (Dev)
```bash
npm run dev
```

### การรัน Unit Tests (Vitest)
```bash
npm test
```

### การ Build โปรเจกต์
```bash
npm run build
```
