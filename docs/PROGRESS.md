# PROGRESS: บันทึกความคืบหน้าและการตัดสินใจของโปรเจกต์ SheetEasy

> เอกสารนี้ใช้บันทึกสถานะจริงของโปรเจกต์ ข้อตกลงพิเศษ บั๊กที่ยังค้างอยู่ และงานถัดไป  
> **กติกา:** เริ่มงานทุกครั้งให้อ่านไฟล์นี้ก่อน และอัปเดตไฟล์นี้ทุกครั้งที่จบงานย่อยหรือก่อน commit

## 1. สถานะของแต่ละ Phase

### Phase 0: ตั้งโปรเจกต์
* **สถานะ:** เสร็จสิ้น (Completed)
* **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
  * โครงสร้าง Electron + Vite + React + TypeScript
  * สคริปต์รัน dev (`npm run dev`) และ build (`npm run build`)
  * ระบบเทสต์ Vitest พร้อมทำงาน (`npm test`)

### Phase 1: แกนหลัก (core + grid พื้นฐาน)
* **สถานะ:** เสร็จสิ้นตามข้อตกลง (Completed with Agreements)
* **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
  * โมดูลคำนวณ `src/core/`: tokenizer, evaluator, functions (20 ฟังก์ชันหลัก + alias MEAN), refshift (คัดลอก/ลาก), shorthand (ไวยากรณ์ย่อภาษาไทย/อังกฤษ), numfmt (บาท, %, วันที่, ทศนิยม), history (Undo/Redo), xlsx (ExcelJS roundtrip)
  * Unit test ฝั่ง core ผ่านทั้งหมด 100% (89/89 tests)
  * Grid พื้นฐานแบบ virtual scroll, แก้ไขเซลในตารางและบน FormulaBar
  * Toolbar: รูปแบบตัวเลข (ทั่วไป, ตัวเลข, บาท, %, วันที่, ทศนิยม +/-), ผสานและแยกเซล
  * ปุ่ม Σ (SUM): คำนวณยอดใต้ช่วงหรือใส่ =SUM(
  * แถบสถานะด้านล่าง: สรุปค่า SUM, AVERAGE, COUNT, MIN, MAX ของช่วงที่เลือกแบบทันที
  * ฟังก์ชันไฟล์: เปิด/บันทึก/บันทึกเป็น (.xlsx) พร้อมกล่องข้อความเตือนไฟล์ที่ยังไม่ได้บันทึก
* **สิ่งที่ยังค้าง/ยังไม่ได้ทดสอบจริง:**
  * การตรวจมือบน Google Sheets จริงตามเช็คลิสต์ `docs/QA-google-sheets.md`

### Phase 2: ใช้งานเหมือน Google Sheets
* **สถานะ:** กำลังทำ (In Progress - ช่วงท้ายของ Phase 2)
* **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
  * Fill handle: ลากเติม 4 ทิศทาง, ต่อลำดับตัวเลข, วันที่, คัดลอกสูตรพร้อมเลื่อน reference, ดับเบิลคลิกเติมลงล่าง, Ctrl+D, Ctrl+R
  * คลิปบอร์ด: คัดลอก/ตัด/วาง รองรับ TSV/HTML จากภายนอก และ Paste Values Only (Ctrl+Shift+V)
  * ปรับขนาดคอลัมน์/แถว: Drag resize และดับเบิลคลิกหัวคอลัมน์เพื่อ auto-fit
  * ตรึงแถว/คอลัมน์ (Freeze panes): ตรึงมุมบนซ้ายตามที่กำหนด
  * ไฮไลต์ Reference: ไฮไลต์สีกรอบและพื้นหลังเซลที่ถูกอ้างอิงตอนแก้ไขสูตร พร้อมกด F4 สลับ reference ($)
  * การแทรก/ลบแถวและคอลัมน์: มีฟังก์ชันปรับขยาย/ย่อข้อมูลและเลื่อนสูตรในตาราง
* **สิ่งที่ยังไม่สมบูรณ์:**
  * Point mode: รองรับเฉพาะคลิกเซลเดียว ยังไม่รองรับการคลิกลากเลือกช่วง (A1:C5) ขณะพิมพ์สูตร
  * เมนูคลิกขวา (Context Menu): แก้ไขบั๊กการแสดงผลและการปิดเมนูแล้ว รองรับ cell, row header, col header ครบถ้วน (รอตรวจมือบน UI)

### Phase 3: ผู้ใช้ทั่วไปใช้ง่าย
* **ก้อน 3A (สไตล์เซล):** เสร็จสิ้น (Completed)
  * **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
    * Toolbar: ตัวหนา, ตัวเอียง, ขีดเส้นใต้ พร้อมแสดงสถานะ active ตามเซลที่เลือก
    * คีย์ลัด: `Ctrl+B`, `Ctrl+I`, `Ctrl+U`
    * จานสีสำเร็จรูป 20 สี + กำหนดสีเอง + ล้างสี สำหรับทั้งสีตัวอักษรและสีพื้นเซล
    * จัดตำแหน่งชิดซ้าย / กึ่งกลาง / ชิดขวา พร้อมระบบจัดอัตโนมัติ (ตัวเลขชิดขวา ข้อความชิดซ้าย)
    * ตัดคำขึ้นบรรทัดใหม่ (Text wrap) แสดงผล word-break ภายในเซล
    * เส้นขอบเซล: ไม่มี / ทั้งหมด / รอบนอก
    * การจัดการข้อมูลร่วมกับสไตล์: Undo/Redo, คัดลอก/วาง, ลากเติม (Fill handle), แทรก/ลบแถว-คอลัมน์ สไตล์ไม่หลุด
    * การวางเฉพาะค่า (Paste Values Only): คงรูปแบบตัวเลขและสไตล์เดิมของเซลปลายทางไว้
    * ExcelJS round-trip: เขียนและอ่านสไตล์ได้ครบถ้วน พร้อมเก็บรักษาฟอนต์ภายนอก (`fontSize`, `fontFamily`) ไม่ให้เสียหาย
* **ก้อน 3B (error ภาษาไทย + ตัวช่วยสูตร + เตือนลบแถว/คอลัมน์):** เสร็จสิ้น (Completed)
  * **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
    * ข้อผิดพลาดภาษาไทย: แสดงชื่อไทยตามสเปก 4.3 (`#หารศูนย์`, `#ค่าผิด`, `#อ้างอิงหาย`, `#ไม่รู้จักชื่อ`, `#วนซ้ำ`, `#สูตรผิด`)
    * Tooltip ภาษาไทยอธิบายสาเหตุและวิธีแก้ไขเมื่อวางเมาส์เหนือเซล error
    * บันทึก error ลงไฟล์ .xlsx เป็นรหัสมาตรฐานสากล (`#DIV/0!`, `#VALUE!`, `#REF!`, `#NAME?`) และแปลง `#CYCLE!` เป็น `#REF!` ตามสเปก
    * ข้อความทั้งหมดรวมอยู่ใน `src/i18n/th.ts`
    * คำเตือนก่อนลบแถว/คอลัมน์: "มีสูตร N เซลที่อ้างถึงแถวนี้/คอลัมน์นี้ ถ้าลบจะขึ้น #อ้างอิงหาย" พร้อมปุ่ม ลบ / ยกเลิก (หากไม่มีสูตรอ้างอิงจะลบทันที)
    * ตัวช่วยสูตร (Formula Helper): โมดอลค้นหาฟังก์ชัน Core ทั้ง 21 รายการ พร้อมชื่อไทย, รูปแบบการใช้, คำอธิบายสั้น, ตัวอย่างภาษาไทย และแผงตัวดำเนินการด่วน
    * ค้นหาฟังก์ชันได้ทั้งภาษาไทยและอังกฤษ (เช่น "รวม", "average", "if")
    * ปุ่ม "ใช้สูตรนี้" ใส่สูตรลงเซลเดิม พร้อมใช้งานร่วมกับ Point Mode ลากเลือกช่วงเซลบนตาราง
    * เข้าถึงตัวช่วยสูตรได้จากปุ่ม Σ "ฟังก์ชันอื่น…" และไอคอน `ƒx` ข้างแถบสูตร
    * Point mode อัปเกรดให้รองรับการคลิกลากเลือกช่วง (`A1:A10`)
    * Vitest automated tests ทั้งหมด 106/106 tests ผ่านครบถ้วน
* **ก้อน 3C (ความทนทานของไฟล์ - File Durability & Robustness):** เสร็จสิ้น (Completed)
  * **สิ่งที่ตรวจแล้วว่าใช้งานได้จริง:**
    * **Atomic File Write:** บันทึกไฟล์แบบ atomic โดยเขียนลงไฟล์ชั่วคราวในโฟลเดอร์เดียวกันก่อนแล้วจึง rename ทับไฟล์จริง หากล้มเหลวจะลบไฟล์ชั่วคราวทิ้งและไม่แตะต้องไฟล์เดิม พร้อมแปลง error code เป็นข้อความภาษาไทยที่ระบุสาเหตุชัดเจน (`EBUSY`/`EPERM` -> ไฟล์ถูกเปิดใช้งานในโปรแกรมอื่น, `EACCES` -> ไม่มีสิทธิ์เขียน, `ENOSPC` -> พื้นที่ดิสก์ไม่พอ, `EROFS` -> ไดรฟ์ Read-only, `ENOENT` -> ไม่พบโฟลเดอร์)
    * **Auto-recovery (ไฟล์กู้คืน):** เมื่อมีการแก้ไขที่ยังไม่บันทึก (`isDirty`) เขียน snapshot อัตโนมัติลงใน `userData/recovery/` ทุก 30 วินาทีแบบ atomic โดยเก็บครบถ้วน: ข้อมูลเซล, สไตล์, ผสานเซล, ความกว้างคอลัมน์, ความสูงแถว, การตรึงแถว, และ path เดิม
    * **Recovery Prompt:** เมื่อเปิดแอป หากพบไฟล์กู้คืนจากการปิดผิดปกติ จะแสดงหน้าต่างถาม "พบงานที่ยังไม่ได้บันทึก กู้คืนหรือไม่" พร้อมปุ่ม กู้คืน / ทิ้ง (หากมีหลายไฟล์จะแสดงรายการให้เลือกตามชื่อไฟล์และเวลาบันทึก) และลบไฟล์กู้คืนเมื่อบันทึกสำเร็จหรือผู้ใช้เลือกทิ้ง
    * **Recent Files (ไฟล์ล่าสุด):** จัดเก็บสูงสุด 10 รายการใน userData (เรียงลำดับใหม่สุดอยู่บนสุด, ไม่ซ้ำซ้อน) แสดงผลในเมนู "เปิดไฟล์ล่าสุด" บน Toolbar และหากไฟล์ถูกย้ายหรือลบไปแล้ว จะขึ้นแจ้งเตือนและลบออกจากประวัติทันที
    * **Drag and Drop:** รองรับการลากไฟล์ `.xlsx` / `.csv` มาปล่อยบนหน้าต่างเพื่อเปิด พร้อมแสดงกรอบไฮไลต์ และหากมีงานค้างที่ยังไม่บันทึกจะแสดงกล่องยืนยันก่อน
    * **Open with & Single Instance:** รองรับการเปิดไฟล์จาก Explorer/Finder ผ่านคำสั่ง "Open with" และลงทะเบียน file association ในตัวติดตั้ง โดยแอปทำงานแบบ Single Instance (ส่งไฟล์เข้าหน้าต่างเดิม พร้อมโฟกัสหน้าต่าง และถามบันทึกหากมีงานค้าง เพื่อประหยัดหน่วยความจำและไม่ให้เกิด session กู้คืนที่ขัดแย้งกัน)
    * **Unsupported Features Banner:** ตรวจจับองค์ประกอบที่แอปยังไม่รองรับในไฟล์ .xlsx ตอนนำเข้า (กราฟ, ตาราง Pivot, รูปภาพ, Conditional Formatting, Data Validation, แผ่นงานที่ซ่อนอยู่) และแสดงแถบเตือนสีเหลืองด้านบนตาราง แนะนำให้ "บันทึกเป็น" พร้อมปุ่มดำเนินการ
    * **Overwrite Guard:** เมื่อกด Ctrl+S ครั้งแรกบนไฟล์ที่มีส่วนที่แอปไม่รองรับ จะแสดงกล่องถามก่อนเขียนทับ (บันทึกทับ / บันทึกเป็นไฟล์ใหม่ / ยกเลิก)
    * **Unsupported Formulas Preservation:** ตรวจจับสูตรที่อยู่นอกเหนือฟังก์ชัน Core (เช่น `VLOOKUP`, `SUMIFS`, `XLOOKUP`) เก็บรักษาข้อความสูตรเดิมและค่า cache เดิมจากไฟล์ นำค่า cache มาแสดงในเซล พร้อมไอคอน ⚠️ และ tooltip "ฟังก์ชันนี้แอปยังไม่รองรับ แสดงค่าเดิมจากไฟล์" และเมื่อบันทึกกลับสูตรเดิมจะไม่เปลี่ยนแปลง
    * **Unsaved Changes Dialog:** แสดงกล่องยืนยันภาษาไทยที่มี 3 ตัวเลือก ("บันทึก", "ไม่บันทึก", "ยกเลิก") เมื่อผู้ใช้จะสร้างตารางใหม่, เปิดไฟล์อื่น, เปิดไฟล์ล่าสุด, ลากไฟล์มาเปิด, หรือปิดหน้าต่างขณะที่มีงานค้าง (`isDirty`)
    * **Window Title:** ชื่อหน้าต่างสะท้อนชื่อไฟล์และเครื่องหมาย `●` เมื่อยังไม่ได้บันทึก (`fileName ● - SheetEasy`)
    * **Vitest automated tests:** ทั้งหมด 125/125 tests ผ่านครบถ้วน 100% (เพิ่มชุดเทสต์ `xlsxDurability`, `fsError`, `recentAndRecovery`, `fsAtomic`, `durabilityStore`)
* **ก้อน 3D:** ยังไม่เริ่ม (รอตรวจ 3C ก่อนเริ่ม)

## 2. ข้อตกลงและการตัดสินใจที่ตกลงกันนอกเหนือจาก SPEC.md

1. **Toolbar Phase 1 และ CellStyle:**
   * Toolbar ใน Phase 1 ทำเฉพาะรูปแบบตัวเลข + ผสาน/แยกเซล ส่วนการจัดสไตล์ตัวหนา/เอียง/สี/ขอบ จะทำใน Phase 3
   * `src/core/xlsx.ts` ต้องอ่าน/เขียน `CellStyle` ได้ตั้งแต่แรก เพื่อไม่ให้สไตล์หลุดเมื่อเปิดไฟล์เดิมแล้วบันทึกกลับ
2. **การเปิดแอปครั้งแรก:**
   * เปิดแอปครั้งแรกเป็นตารางว่างเปล่าเสมอ ส่วนตัวเลือกเทมเพลตรายรับรายจ่ายจะทำใน Phase 3
3. **พฤติกรรมปุ่ม Σ:**
   * ถ้าเลือกช่วงไว้ ให้ใส่สูตรผลรวมใต้ช่วง
   * ถ้าไม่ได้เลือกช่วง ให้แทรก `=SUM(` รอไว้ในช่องแก้ไขเซล
   * การเดาช่วงตัวเลขอัตโนมัติอยู่ Phase 2
4. **การบันทึกไฟล์และความปลอดภัย:**
   * การบันทึกไฟล์ใช้ File Dialog + `fs.writeFile`
   * ไฟล์กู้คืน 30 วินาที ไว้ Phase 3
   * การเขียนไฟล์แบบกันไฟล์เสีย (เขียนไฟล์ชั่วคราวแล้ว rename) ถ้าทำได้ในไม่กี่บรรทัดให้ทำก่อนใน Phase 1-2 ได้ ถ้าไม่ได้ไว้ Phase 3
